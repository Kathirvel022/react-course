# 🚀 React Course 

## 📌 What is React?

React is a **JavaScript library** used to build **user interfaces (UI)**.

- Created by Facebook
- 2011 in FB
- 2013 open source
- Used to build **single page applications (SPA)**
- Component-based architecture

---

## 🎯 Why React?

- Fast (uses Virtual DOM)
- Reusable components
- Easy to manage UI
- Huge community support

---

## 🧠 Prerequisites

Before learning React, you should know:

- HTML (basic tags)
- CSS (basic styling)
- JavaScript (ES6 basics)
  - let, const
  - arrow functions
  - functions
  - arrays & objects
